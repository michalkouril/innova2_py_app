# Innova-2 XRT shell register map (fp8c lineage) — as used by innova2-smi

Generated by `innova2-smi regmap --markdown` from `innova2_smi_regmap.py`. The authority is the read multiplexer in `ip_src/ddr_health/ddr_health.v` of the shell source; `innova2-smi regmap --check-rtl <ddr_health.v>` compares the two (offsets, and which offsets the RTL decodes).

**Never read an offset that is not listed for the running shell.** An undecoded management-PF read hard-locks the host. innova2-smi reads OBS_ID (mgmt BAR0 0x36030) first and refuses every other access on an OBS_ID that is not below.

| 0x0B5E0003 | E7a (edge-gating throttle; development build) | - | yes | - | - |

## Management PF BAR0 regions used

| base | size | block |
|---|---|---|
| 0x032000 | 0x1000 | mgmt_memcalib axi_gpio: calibration bit (GPIO), DDR mode register (GPIO2) |
| 0x036000 | 0x1000 | mgmt_status = ddr_health (12-bit AXI-Lite; every undefined offset reads 0) |
| 0x040000 | 0x1000 | mgmt_flash axi_quad_spi (rawspi; flash-verify only) |
| 0x0A0000 | 0x1000 | system_management_wiz_0 AXI view (DRP register file at +0x400) |

Fixed registers: 0x32000 [0] XRT calibration bit; 0x32008 [1:0] requested DDR mode (0 on, 1 off, 2 emu, 3 hybrid); SYSMON DRP register d at 0xA0400 + 4*d (temperature 0x00, VCCINT 0x01, VCCAUX 0x02, VCCBRAM 0x06, max 0x20-0x23, min 0x24-0x27).
