# Innova-2 XRT shell register map (fp8c lineage) — as used by innova2-smi

Generated by `innova2-smi regmap --markdown` from `innova2_smi_regmap.py`. The authority is the read multiplexer in `ip_src/ddr_health/ddr_health.v` of the shell source; `innova2-smi regmap --check-rtl <ddr_health.v>` compares the two (offsets, and which offsets the RTL decodes).

**Never read an offset that is not listed for the running shell.** An undecoded management-PF read hard-locks the host. innova2-smi reads OBS_ID (mgmt BAR0 0x36030) first and refuses every other access on an OBS_ID that is not below.

Layout column: the last hex digit of the OBS_IDs that decode the offset (1 = full, 2 = E4 layout, 3 = E7a, 4 = E7b, 5 = E7a2, 6 = E7a3, 7 = E7a3-2666ca48, 8 = route V, B = route V r2).

Route V (OBS_ID 0x0B5E0008, VBNV innova2_innova2_noddr_202320_3): the DDR4 MIG lives in the dynamic region; an xclbin either has it (KEPT: its kernels use bank0) or not (PRUNED). 0x00-0x198 keep the E7a3 meaning; 0x14-0x2C stay cumulative since configuration (the in-RP ECC poller sends deltas over the RP boundary) and 0x1D0-0x1E8 hold the same values for the current load only. 0x10 [16] needs a KEPT xclbin to become 1. XRT's calibration bit (0x32000 [0]) is the KEPT MIG's calibration, and 1 under a PRUNED xclbin. The DDR mode register keeps its 2 bits but the gate runs ON/OFF only: a requested EMU runs ON and HYBRID runs OFF (EMU/HYBRID deferred). Fences while PRUNED are expected (no DDR), fences while KEPT are counted at 0x1EC. Recorder types 20 RM_DDR, 21 CAL_DONE, 22 CAL_LOST.

Route V r2 (OBS_ID 0x0B5E000B, same VBNV): the route-V map plus 0x218 FENCE_LDWIN / 0x21C FENCE_OUTWIN / 0x220 FENCE_WIN. A link-down window is open while the link is down, the link-down MIG reset is active, or (after a link-down) the static waits for recalibration and less than 2 s have passed since link-up; it closes at RECAL_DONE or at the limit. FENCE_LDWIN + FENCE_OUTWIN = FENCE (0xA0). The r2 flash image boots with the PRUNED filler in the dynamic region, so RV_INFO/DDR_INFO read 'no DDR' until a KEPT xclbin loads.

PR_COUNT (0x120) counts RP ISOLATIONS: XRT isolates the RP twice per `xbutil program` (a zero-length isolate first, then the reconfiguration), so it rises by 2 per xclbin load. Route V's RV_LOADS (0x1C4) counts each load once, 262 us after its release, plus the configuration's own RM at power-on.

Units: timestamps are uptime[47:16] (262.144 us); recorder records are 64 bits, [63:58] type [57:40] payload [39:0] uptime[47:8] (1.024 us). Temperature code to C: code * 509.3140064 / 1024 - 280.2308787.

Throttle power-on defaults: E7a2 THR_CTRL 0x31, THR_THRESH 0x02D402E9 (745/724); E7a3 THR_CTRL 0x31, THR_THRESH 0x02C102D5 (725/705 = 80.37/70.42 C), THR_THRESH2 0x02D502E9 (745/725 = 90.31/80.37 C), THR_TIER 0x00010100.

## MIG configuration per build (`innova2-smi ddr`)

No shell reports its MIG configuration in a register, so innova2-smi keeps this table by ROM_TS (read from each build's generated MIG RTL, IP parameters, par XDC, CA-drive gate and create_project log). Timing in DDR4 clock cycles; every build's PHY is 4:1, so ui_clk = 1/(4 tCK) and MT/s = 8 x ui_clk. The ui_clk is measured passively: the ECC poller completes one poll per POLL_CYC ui_clk cycles (0x2C counts them), timed by the 250 MHz uptime counter (0xB0/0xB4); precision about 2/polls + 0.08 %.
